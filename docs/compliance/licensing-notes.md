# Licensing Notes

This codebase is a clean-room commercial-grade implementation.

## Allowed

- Reuse high-level product ideas from MIT-licensed projects when license terms are preserved.
- Use public official documentation and statutory requirements as compliance references.
- Recreate UX patterns from observed professional software without copying code, assets, or
  proprietary expression.

## Not Allowed Without Explicit Approval

- Import GPL-3.0 code into this proprietary codebase.
- Import AGPL-3.0 code into this proprietary codebase.
- Copy no-license repository code.
- Copy compliance logic from third-party repositories whose license is incompatible or unknown.

## Current Handling

- TaxHacker-like concepts are represented as clean-room document ingestion and extraction
  workflows.
- India Compliance is treated as a behavioral domain reference only, not a code source.
- Mike is treated as UX inspiration only, not a code source.
- Simplify-Tax and TaxInvoiceApp are treated as lightweight conceptual references only.

Any copyleft experiment must live in a clearly separated branch named `copyleft-prototype` and must
not be merged here without accepting the relevant license obligations.
